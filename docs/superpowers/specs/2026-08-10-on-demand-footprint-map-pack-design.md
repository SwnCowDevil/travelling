# 足迹地图按需下载包设计

## 背景

全国原始行政区边界包含约 79.8 万坐标点，首屏接口约 18 MB；直接传给小程序并在 Canvas 绘制会造成足迹页长时间卡顿。

## 目标

- 足迹页在未准备地图资源时仍可立即使用列表模式。
- 用户主动切换地图模式后，确认下载一次轻量中国地图包。
- 下载完成后的地图支持现有省级→市级下钻、状态点亮和返回全国。
- 地图包保存在微信本地文件缓存；后续打开无需再次下载。
- 下载、解析或绘制失败时自动保留列表模式并给出可理解提示。

## 方案

### 资源生成与发布

后端从既有 `region_boundaries` 原始缓存生成版本化的静态地图包。每个省、市边界只保留面积较大的 12 个多边形，并将每个行政区限制为 360 个坐标点。原始边界继续保留在数据库中，不被覆盖。

地图包由专用只读接口返回元信息（版本、字节数、下载地址、MD5 校验值）和文件内容。常规 `/map/summary` 仅返回区域状态、名称和中心点，不再返回 `polygons`，避免首屏携带大几何数据。

### 小程序交互

1. 进入足迹页默认加载列表及状态摘要。
2. 用户点“地图”时，若本地没有当前版本的地图包，弹出说明：下载一次后可离线查看中国地图。
3. 用户确认后显示下载进度；下载文件、校验、解析成功后写入本地缓存并切换到地图。
4. 用户取消、网络失败或资源异常时停留在列表模式，可再次点击地图重试。
5. 本地版本与服务端版本一致时直接读取缓存，不弹窗、不联网下载。

### 性能与容错

- 地图包目标大小为数百 KB；单个行政区最多 360 点、12 条路径，以控制 Canvas 投影和命中测试成本。
- 下载使用微信异步 API 与进度回调；不阻塞列表交互。
- 解析后的对象只保存在当前页面内；持久化保存文件、版本、字节数与 MD5，避免反复写入大 JSON 字符串。
- 无网络时若有缓存继续显示地图；无缓存则维持列表模式。

## 验收标准

- 足迹首屏不请求全国原始 `polygons`，可快速显示列表。
- 首次地图切换出现下载确认和进度；取消后不影响列表。
- 下载后的地图可以点亮状态、省市下钻和返回全国。
- 再次打开足迹页不重复下载同一版本。
- 失败时不白屏、不卡死，并提供重试入口。
