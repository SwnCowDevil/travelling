# 本地开发服务脚本设计

## 目标

为 macOS 上的微信开发者工具提供可重复、不会误杀其他进程的 FastAPI 本地启停方式。小程序通过 `http://127.0.0.1:8000` 访问后端，本次不包含真机局域网访问和本地 HTTPS。

## 命令入口

- `scripts/start-local.sh`：检查环境、执行迁移、后台启动服务并验证健康状态。
- `scripts/stop-local.sh`：只停止本项目 PID 文件记录的服务。
- `scripts/status-local.sh`：显示运行状态、API 地址和日志位置。

三个脚本均以仓库根目录为基准解析路径，因此可以从任意当前目录调用。运行时文件统一放在仓库根目录的 `.local/`，并加入 `.gitignore`。

## 启动流程

启动脚本检查 `backend/.venv/bin/uvicorn` 和 `backend/.env`。缺失时输出明确的修复方法并以非零状态退出。随后在 `backend` 工作目录执行 Alembic 升级，使用 `127.0.0.1:8000` 和单进程 Uvicorn 后台启动 API，将 PID 写入 `.local/backend.pid`、输出写入 `.local/backend.log`。

脚本轮询 `/health`，只有收到成功响应才报告启动完成。超时或进程提前退出时打印日志尾部、清理失效 PID 并返回失败。若 PID 文件对应的本项目进程已经运行，重复启动只报告当前地址，不创建第二个进程。

## 停止和状态检查

停止脚本读取 PID 后先核对该进程命令包含当前仓库的 Uvicorn 启动特征，确认后发送 `TERM` 并等待退出。超时才报告失败，不使用不受控的批量杀进程命令。PID 不存在、进程已经退出或 PID 文件失效时执行幂等清理。

状态脚本使用相同校验规则，运行时显示 API 与健康检查结果；未运行时返回用户可读状态。日志不会记录或输出 `.env` 内容。

## 小程序配置

新增不含敏感信息的 `miniprogram/miniprogram/config/local.js`，导出 `http://127.0.0.1:8000`。`app.js` 从该文件读取 API 地址。微信开发者工具本地调试时需要开启“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。该 HTTP 地址仅用于开发者工具，不用于真机或正式发布。

## 验证

- 脚本静态语法检查通过。
- 首次启动后 `/health` 返回 `{"status":"ok"}`。
- 重复启动不产生第二个服务进程。
- 状态脚本能识别运行中服务。
- 停止后进程退出，重复停止保持成功。
- 后端和小程序现有测试继续通过。
