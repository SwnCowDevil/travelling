# 足迹页轻量点亮地图设计

## 目标

将“我的足迹”默认展示为深色中国行政区地图，使用户能直观看到已点亮的旅行区域，同时保留现有列表管理能力。

## 范围与限制

- 微信小程序不能直接运行高德交互式 JS 地图并叠加行政区块。因此地图使用高德行政区编码/边界数据作为来源，前端绘制轻量矢量地图。
- 不实现卫星底图、自由缩放拖动、轨迹、时间轴、世界视图、角落覆盖率或路线距离统计。
- 不改动现有足迹状态、到访记录、筛选语义和用户隔离逻辑。

## 地图模式

1. 足迹页默认打开“地图”模式，展示深色背景、简化的中国行政区轮廓与轻量目的地点。
2. 已记录“去过”的区域使用主青绿色点亮；“想再去”使用较深青绿；“想去”使用浅青绿；“不想去”保留深灰，避免将负向状态误识别为点亮。
3. 地图顶部展示当前层级名称、当前层级已点亮数及状态筛选项。
4. 地图点击流程为中国（省级）→ 省（市级）→ 市（县级）。每次下钻仅请求并绘制当前行政区的直属下级区域。
5. 每个区域点击后进入下一级；无下级或无可用边界时，保留当前层级并提供现有的列表信息。
6. 当前目的地仍可作为地图点位叠加；点击区域与地点不会改变已有“想去／去过／想再去／不想去”的管理操作。

## 列表模式与切换

- 页面右上角增加“地图 / 列表”切换控件。
- “列表”模式沿用当前区域卡片、状态筛选、下钻和到访记录入口。
- 模式切换仅改变呈现方式，保留相同的层级、筛选状态和已加载数据；页面重新打开时默认地图模式。

## 数据与渲染

- 后端在现有 `/map/summary` 基础上提供当前层级区域的简化边界与中心点；缓存边界数据，避免每次进入地图页请求高德。
- 前端将边界坐标按当前视口投影到 Canvas，按聚合后的直接状态填充区域，并在中心位置绘制名称与可选地点标记。
- 当边界请求失败或 Canvas 不可用时，自动回退到现有列表模式并显示简短提示，不丢失足迹管理能力。

## 测试

- 后端测试：当前层级地图摘要仅返回直属下级、状态聚合及边界回退行为。
- 前端模型测试：状态颜色映射、地图/列表模式切换、下钻层级与筛选保持。
- 前端视图测试：地图默认入口、右上角切换、Canvas 容器和列表回退提示。
