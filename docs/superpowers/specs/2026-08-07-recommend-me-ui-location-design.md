# 推荐页、我的页设计稿还原与定位修复设计

## 1. 目标

将微信小程序的“推荐”和“我的”页面还原到 `travel-miniprogram-mockup.html` v4 的信息架构、配色、卡片与动效风格，同时保留现有后端接口、AI 设置、到访记录和旅行地图等真实能力。修复当前微信开发者工具中无法选择出发地的问题。

## 2. 范围

### 2.1 本批包含

- 推荐页 WXML、WXSS、交互状态和组件样式重构。
- 我的页 WXML、WXSS、统计数据和菜单导航重构。
- 定位隐私权限声明、失败处理、重新授权与手动选址。
- 推荐筛选交互：月份、淡旺季、人流、偏好、更多。
- 推荐结果卡片与加载动效。
- 相关前端回归测试和微信 WXSS 兼容性检查。

### 2.2 本批不包含

- 旅行地图页的视觉重构。
- 目的地详情页的视觉重构。
- 新的后端业务模型或第三方天气服务。
- 正式环境的微信 AppSecret 申请和云端部署。

## 3. 视觉基准

以 HTML v4 为唯一页面视觉参考，使用以下核心设计令牌：

- 主色 `#1BB28A`，深主色 `#159C77`，浅主色 `#E6F7F2`。
- 强调色 `#FF9F43`，页面背景 `#F4F5F7`，卡片背景白色。
- 主卡片圆角约 `32rpx`，轻量绿色或中性阴影。
- 优先使用微信原生与 Vant Weapp 支持的 WXSS，不使用已知无法编译的 CSS 能力。
- 保留渐变移动、卡片渐入、按钮按压、骨架屏和头像轻浮动；不引入影响操作的长动画。

## 4. 推荐页

### 4.1 页面结构

1. 顶部绿色渐变 Hero：标题“旅行推荐”、说明文案、当前地区和“切换定位”操作。
2. 五列筛选栏：月份、季节、人流、偏好、更多。
3. 当前筛选条件摘要标签，每项可单独清除。
4. 主操作“一键推荐”。
5. 结果区：推荐依据、加载骨架、降级提示、推荐卡片和换一批。

### 4.2 筛选交互

- 同一时间只打开一个筛选面板，点击遮罩或确定关闭。
- 月份单选，默认当前月份。
- 季节、人流、偏好和分类支持多选，也允许不选。
- “更多”包含最推荐、分类和已有的距离、预算、天数、交通筛选入口；对暂无完整控件的条件保留可扩展结构，不伪造已生效数据。
- 页面发送的请求仍通过现有 `buildRequest` 转换，不改变后端契约。

### 4.3 推荐卡片

- 还原 HTML 的图形缩略区、名称、推荐指数、标签、“最推荐”徽标。
- 展示“怎么去”、“天气”、“注意”三列摘要；后端数据缺失时显示稳定占位文案，不使用 `undefined`。
- 底部保留“标记去过”、“想去”、“不想去”。按钮点击更新真实状态，卡片非按钮区域进入详情。

## 5. 出发地与隐私权限

### 5.1 权限声明

- `app.json` 增加 `permission.scope.userLocation.desc`。
- `app.json` 增加 `requiredPrivateInfos` 中的 `getLocation` 与 `chooseLocation`。
- 文案明确说明位置仅用于计算距离和推荐出发地。

### 5.2 交互流程

1. 页面加载时尝试获取当前位置。
2. 成功时显示“当前位置”，使用 GCJ-02 坐标。
3. 用户点击“切换定位”或在未选址时点击推荐，调用微信地图选址。
4. 若权限被拒绝，显示可操作弹窗，引导用户打开设置重新授权。
5. 若用户取消选址，保留原地址并结束待推荐状态，不自动发请求。
6. 手动选址成功后保存最近出发地；若本次由“一键推荐”触发，则自动继续推荐。

## 6. 我的页

### 6.1 页面结构

1. 绿色渐变用户区：微信头像或默认头像、“微信用户”默认名称、个人旅行空间说明。
2. 三列统计：去过、想去、不想去。
3. 第一组功能：我的旅行地图、到访记录、AI 设置。
4. 第二组功能：消息通知与旅行伙伴标记“待扩展”，设置和关于保留入口样式。

### 6.2 数据与导航

- 头像使用 `chooseAvatar`，选择后立即更新。
- 统计数据优先来自地图摘要接口；请求失败时显示 0，页面仍可操作。
- 旅行地图使用 `switchTab`，到访记录和 AI 设置使用 `navigateTo`。
- 待扩展项不跳转，点击可提示“敬请期待”。

## 7. 错误处理

- 定位取消、权限拒绝和 API 失败分开处理，不再使用空 `catch`。
- 登录未完成时，推荐请求等待 `authReady`。
- 推荐失败后恢复按钮和加载状态，保留已有结果或显示可理解的空状态。
- AI 不可用时继续使用后端规则推荐，并在结果区标注来源。

## 8. 测试与验收

### 8.1 自动测试

- 定位成功、取消、拒绝、重新授权和手动选址。
- 未选出发地时一键推荐的继续流程。
- 筛选状态的选择、清除和请求转换。
- 我的页统计数据转换与导航。
- 页面关键结构与 WXSS 编译兼容检查。
- 现有前端和后端全量测试不回归。

### 8.2 微信开发者工具验收

- 推荐页和我的页在常见 iPhone 模拟器宽度下与 HTML v4 的层级、配色、间距和卡片风格一致。
- 首次定位、拒绝后重试、手动选址和更换地址均有可见反馈。
- 选址后“一键推荐”发出 `POST /recommendations`，并渲染结果卡片。
- 我的页头像选择、旅行地图、到访记录和 AI 设置入口可用。
- 控制台无 WXML/WXSS 编译错误和未捕获 Promise 异常。

## 9. 安全与部署边界

- 小程序内不保存微信 AppSecret、系统 AI Token 或高德服务端密钥。
- 本地调试登录仅由本地启动脚本显式开启，后端默认关闭。
- 上线前需将前端登录切换为正式微信登录，不在本批变更正式环境配置。
