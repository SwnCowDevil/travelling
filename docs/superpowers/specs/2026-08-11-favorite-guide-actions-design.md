# 收藏攻略操作按钮设计

## 目标

提升收藏攻略详情页的编辑与删除操作辨识度，避免胶囊按钮造成主次不清。

## 布局与视觉

- 操作区保持横向两列等宽布局，两个按钮高度统一为 76rpx、圆角 18rpx。
- 非编辑态：左侧“编辑攻略”为绿色实心主操作；右侧“删除收藏”为白底红色描边危险操作。
- 编辑态：左侧“保存修改”为绿色实心主操作；右侧“取消”为白底灰色描边操作；删除按钮独占下一行。
- 文字使用 Flex 垂直、水平居中，去除微信原生 button 的默认边框和外边距。

## 行为与验证

- 不改动编辑、保存、取消和删除事件。
- 增加视图测试，断言横向网格、矩形尺寸、危险按钮描边和主要按钮填充色。
