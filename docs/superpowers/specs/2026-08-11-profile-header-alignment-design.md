# 个人页头部左对齐设计

## 目标

让头像位于左侧，用户名与“你的个人旅行空间”位于头像右侧并左对齐；二者之间保持 20rpx 间距，不贴紧也不分散。

## 实现

- 保持 `.me-hero` 的横向 Flex 布局和既有内边距。
- 将其 `gap` 从 30rpx 调整为 20rpx。
- `.profile-copy` 明确为 `flex: 0 1 auto` 和 `text-align: left`，阻止文字区域占满右侧空白并固定左对齐。
- 不调整头像尺寸、上传交互、渐变背景或统计卡片。

## 验证

- 为个人页视图测试断言 20rpx 间距与文本左对齐。
- 运行小程序全量测试。
