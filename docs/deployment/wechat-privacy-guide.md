# 微信小程序隐私保护指引填写清单

> 适用项目：去哪里（AppID `wx18e666d60871a012`）  
> 用途：根据当前代码整理微信公众平台“用户隐私保护指引”的填写依据。正式提交时仍需按公众平台当时的字段和实际运营方式核对。

## 一、实际处理的信息

| 信息 | 使用目的 | 获取方式 | 保存情况 |
| --- | --- | --- | --- |
| 精确位置、手动选点的经纬度和地址 | 选择出发地、反向地理编码、计算与目的地的距离 | 用户触发 `getLocation` 或 `chooseLocation` 并完成微信隐私授权 | 最近一次手动出发地保存在小程序本地存储；攻略和推荐请求会按功能需要发送给后端 |
| 微信用户标识 `openid` | 登录、区分不同用户的收藏、足迹和 AI 设置 | 通过微信登录凭证由后端向微信接口换取 | 保存在后端数据库 |
| 目的地状态、到访记录、去过次数、想去/不想去/再想去 | 管理个人旅行足迹与分类 | 用户主动标记或编辑 | 保存在后端数据库，可删除具体到访记录 |
| 收藏的攻略及用户编辑内容 | 保存、展示和编辑个人行程 | 用户点击“收藏攻略”或主动编辑 | 保存在后端数据库，可在收藏详情中删除 |
| 个人 AI Token、API 地址和模型设置 | 允许用户选用自己的 AI 服务 | 用户在“我的 → AI 设置”主动填写 | Token 在后端加密后保存，前端只展示脱敏值；可恢复系统默认以删除个人配置 |

## 二、第三方处理方

- 微信：提供小程序登录、位置能力和隐私授权界面。
- 高德地图：接收搜索词、地区信息或经纬度，用于目的地搜索和反向地理编码。
- DeepSeek 官方 API：接收生成攻略或推荐所需的出发地、目的地、月份、天数和偏好，用于生成或排序旅行内容。不应在提示词中加入姓名、证件号等无关个人信息。
- 阿里云：承载后端服务和数据库。需在隐私指引中填写实际云服务所在地和运营主体。

## 三、头像说明

当前“我的”页的微信头像只用于小程序当次界面展示，现有代码没有上传头像到后端。如后续增加上传或持久化，必须同步修改隐私指引。

## 四、用户权利与审核前缺口

当前已有的操作：

- 收藏攻略可在收藏详情页删除。
- 到访记录可在到访记录页删除。
- 个人 AI 配置可通过“恢复系统默认”删除。

正式提审前必须补齐：

1. 提供可用的运营者联系方式，用于用户申请查询、更正、复制或删除个人信息。
2. 当前没有“注销账号/删除全部个人数据”入口。上线前应实现账号级删除，或在隐私指引中明确可执行的人工申请流程和处理时限。
3. 补充实际数据保留期限、运营者名称、联系方式和服务器地域，不要留为模板文字。

## 五、微信公众平台核对项

- 隐私保护指引中声明“精确位置”，用途与 `app.json` 中“选择出发地和计算旅行距离”保持一致。
- 核对平台中 `getLocation` 和 `chooseLocation` 两项接口申明。
- 核对用户信息是否会提供给高德、DeepSeek 和阿里云，并按平台页面的实际分类填写。
- 用真机首次进入推荐页、点击“切换定位”各验证一次：授权前不得调用位置接口，拒绝后可使用已保存的出发地，或稍后重新发起隐私授权。

## 六、AI 内容标识与合规跟进

- 推荐结果、目的地详情和收藏攻略已按真实来源显示“AI 生成”或“规则参考”；用户编辑 AI 攻略后显示“AI 生成 · 已编辑”。
- 正式上线前，向 DeepSeek 或实际模型服务商获取需展示的模型备案号/上线编号，并根据小程序实际服务形式核对是否需要履行生成式 AI 应用登记。
- 该清单是产品与技术核对材料，不替代法律意见或微信审核结论。

## 七、DeepSeek 官方 Key 安全配置

不要把 Key 发到聊天、提交到 Git 或写进小程序前端。使用项目脚本在终端中隐藏输入：

```bash
# 本地
./scripts/configure-deepseek.sh backend/.env

# 服务器（代码已同步到 /opt/travelling 后）
/opt/travelling/scripts/configure-deepseek.sh /etc/travelling/travel-api.env
/opt/travelling/scripts/restart-backend.sh
curl -fsS http://127.0.0.1:8000/health
```

脚本会先备份原配置，再写入官方地址、Pro/Flash 模型和 Key，验证输出不显示 Key 原文。
